# Presentator — один файл EXE

Для развертывания распространяется **только** `target\release\presentator.exe`.
Вшитые PDFium и libmpv не требуют дополнительных файлов рядом с программой.
При первом запуске они автоматически извлекаются во внутренний кэш
`%LOCALAPPDATA%\Presentator` (аналогичный механизм уже применялся для libmpv).

## Сборка (Windows x64)

В полном репозитории Presentator запустите:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_release.ps1
```

Сценарий автоматически скачает PDFium x64 7881 на компьютере **сборки** при
первом запуске. В рабочем EXE зависимости уже находятся внутри. На компьютере
показа интернет не требуется. Скрипт не подменяет уже существующие ресурсы.

**Важно:** в переданном AI-экспорте не было бинарных ресурсов самого
Presentator (`libmpv-2.zip`, значки), поэтому сборку нужно делать в полном
рабочем проекте. Убедитесь, что скрипт завершился успешно.

Подробные тесты: `PDFIUM_TESTS.md`.
