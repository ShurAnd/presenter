# Presentator Stage 17 — первое открытие PPTX и выравнивание строки фокуса

Пакет поверх прежних исправлений Stage 17. Распакуйте поверх папки проекта с заменой src/ppt.rs, src/commands.rs и src/ui.rs.

Активация окна PowerPoint теперь восстанавливает свёрнутое окно и повторно поднимает его над другими окнами; при команде «Фокус» Presentator повторяет попытку каждые 200 мс в течение окна проверки ответа. Это покрывает задержку первого запуска PowerPoint и отказ Windows на единичный запрос.

Строка статуса фокуса центрирует всю группу текста и кнопки по ширине панели. При закрытой презентации она скрыта.

В PowerShell из папки проекта:

    cargo test --all-targets
    cargo build --release

Закройте старые копии, запустите собранные target\release\presentator.exe на сервере и операторе. Проверьте первый запуск PPTX, потерю фокуса и кнопку «Фокус». Убедитесь, что строка статуса выровнена по центру.

Сборка и проверка поведения Windows/PowerPoint в среде подготовки недоступны; архив проверен на целостность.
