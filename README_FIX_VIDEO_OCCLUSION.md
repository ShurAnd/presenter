# Presentator 2.5.1 — исправление перекрытия видео сценой

## Что исправлено

При работе нескольких копий Presentator на одном компьютере сцены имеют одинаковый заголовок. Windows могла найти сцену другой копии, поэтому нужная сцена оставалась поверх видео. Теперь приложение находит окно сцены только в своём процессе и меняет порядок окон у правильного окна.

## Установка в Windows PowerShell

1. Распакуйте архив во временную папку.
2. Из корневой папки проекта выполните:

```powershell
Copy-Item .\src\ppt.rs .\src\ppt.rs.bak
Copy-Item 'ПУТЬ_К_РАСПАКОВАННОМУ_АРХИВУ\src\ppt.rs' .\src\ppt.rs -Force
cargo build --release
```

Замените `ПУТЬ_К_РАСПАКОВАННОМУ_АРХИВУ` на фактический путь, например `D:\Downloads\Presentator_2.5.1_video_occlusion_fix`.

Проверьте запуск видео на дополнительном мониторе. Если на компьютере запущены две копии Presentator, проверьте и этот сценарий.
