## Добавлено

- Hayro: три цикла «несуществующая страница → фрагмент корректной страницы → полная страница» через один Renderer. Проверяются ключ ответа, размеры, число пикселей и цвет содержимого. Ошибка страницы не должна ломать дальнейшие задания.
- Hayro: ошибка миниатюры → корректная миниатюра через тот же Renderer. Проверяется возможность декодировать доставленный JPEG и его размеры.
- PowerPoint: один Host, четыре открытия и три принудительных перезапуска. После каждого открытия проверяются Ready, переход на третий слайд и возврат на второй; после restart — сброс состояния и завершение зарегистрированного процесса. Из очереди разрешены только события текущей и непосредственно предыдущей сессии.
- Видео: реальный движок, абсолютная перемотка на паузе, относительная перемотка назад, старт, пауза, продолжение и достижение конца. Каждое действие подтверждается событием движка, без фиксированных sleep. Переходы перемотки пересекают целую секунду, поскольку приложение публикует позиции при изменении целочисленной секунды.

Графические окна создаются только при явном -Native; автоматизации мыши/клавиатуры нет. Используется существующий opt-in и предзапусковая проверка этапа 13. Никогда не запускайте все ignored-тесты разом: среди них есть тест изменения автозапуска в реестре.

## Windows PowerShell

Из папки проекта сначала запустите обычный регрессионный прогон:

```powershell
cd D:\rust_projects\presenter
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify_stage15.ps1
```

Ожидается на Windows: 376 passed, 0 failed, 27 ignored. Это ожидаемое число, не результат запуска в среде разработки.

Затем закройте все PowerPoint и выполните на отдельном тестовом рабочем столе полный замер:

```powershell
rustup run nightly powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\coverage_report_stage15.ps1 -Branch -Native -IUnderstandWindowAutomation -StressLoopback
```

Будут выполнены основные тесты, localhost stress и семь выбранных нативных тестов. Нужны существующие tests\fixtures\stage12_three_slides.pptx и stage12_video.mp4, vendor\pdfium\pdfium.dll, cargo-llvm-cov и llvm-tools-preview для nightly.

Результат для отправки: target\Presentator_stage15_coverage.zip. При ошибке пришлите текст ошибки и соответствующие stdout/stderr из target\presentator-coverage\stage15-logs. Нативные проверки и Rust-компиляция этого пакета в Linux-среде подготовки не выполнялись: cargo, PowerShell и PowerPoint здесь недоступны. Рост покрытия заранее не заявляется.
