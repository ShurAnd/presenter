# Presentator 2.5.2

Патч поверх 2.5.1 с последним обновлением remote_focus_pdf_settings.

## Установка

Сделайте резервную копию Cargo.toml, Cargo.lock и папки src.
Скопируйте содержимое архива в корень проекта с заменой файлов.

В Windows PowerShell из корня проекта:

```powershell
cargo test --all-targets stage20_
cargo test --all-targets
cargo build --release
```

После успешной сборки закройте старые копии программы и установите новый
EXE из target\release на компьютер показа и компьютер оператора.
В заголовке и настройках должна появиться версия 2.5.2.

## Изменения интерфейса

- Статус видео/слайда вынесен в отдельную строку над кнопками.
- Команды показа переносятся на следующую строку при нехватке ширины.
- Кнопки видео подписаны «Старт видео», «Пауза видео», «Продолжить видео».
- Фон, часы, таймер, переход к слайду, курсор и справка собраны в служебной строке.
- Сообщение сервера/операции располагается отдельно и сокращается по ширине.
  Полный текст доступен при наведении.
- Названия файлов и состояние в списках презентаций и музыки имеют отдельные
  области. Длинный текст сокращается с многоточием. Полное имя видно при наведении.
- В верхней строке явно указано «Оператор → …» или «Сервер показа».
- Кнопки «Вверх», «Вниз» и «Очистить» видны на вкладках со списками.
- Пустые списки дают короткую инструкцию по добавлению файлов.
- Для картинки показан статус «Изображение на экране».

## Проверка

Открыть окно размером примерно как на присланных скриншотах (750 × 650).
Проверить видео в состояниях подготовки, готовности, воспроизведения и паузы.
Проверить длинные русские/английские названия презентаций и аудио, а также
длинное сообщение сервера. Текст не должен перекрывать кнопки и соседнюю колонку.
Проверить «Перейти», курсор, фон, часы и таймер, затем потерю/возврат фокуса через оператора.

Добавлены два регрессионных теста egui без настоящих окон:
- отсутствие пересечения статуса видео с надписями основных кнопок при ширине 520/750/1000;
- одна строка и ограничение области отрисовки длинного названия.

В среде подготовки нет Rust и Windows. Сборка, Rust-тесты и визуальная проверка
запущенного приложения здесь не выполнены. Проверены номера версий в Cargo.toml/
Cargo.lock и целостность ZIP.
