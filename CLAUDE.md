# Presentator

Полная сводка проекта (цель, архитектура, протокол, решения, статус, план): @PROJECT.md

## Правила работы

- Общение и комментарии в коде — на русском.
- Над проектом работают с двух компьютеров (дом и работа), контекст переносится только через git.
  В конце значимой сессии обновлять `PROJECT.md`: разделы «Что сделано», «Что и как проверено», «Известные проблемы», «Что осталось сделать».
- Сборка: `cargo build --release` → `target/release/presentator.exe`.
- Состояние приложения меняется только в GUI-потоке; другие потоки шлют события через `mpsc` и будят GUI через `request_repaint()`.
- Все действия пользователя проходят через `Cmd` → `App::act` → (сервер или) `App::apply`.
