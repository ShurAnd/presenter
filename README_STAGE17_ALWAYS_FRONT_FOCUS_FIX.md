# Presentator 2.4.1 Stage 17 — слои окон и фокус видео/картинок

Это исправление заменяет предыдущую версию always_front. Распакуйте архив поверх папки проекта с заменой файлов.

Исправлено:
- Сцена больше не поднимается поверх активного PPTX. При показе PPTX PowerPoint находится над сценой; после закрытия сцена с фоном возвращается выше обычных окон.
- Для PDF, картинок и видео приложение проверяет фокус окна сцены. Строка фокуса и кнопка «Фокус» теперь работают для всех этих типов.
- Картинки отображаются внутри сцены, поэтому остаются в том же верхнем слое, что и PDF.
- При видео проигрыватель сохраняется над сценой, а сцена остаётся непосредственно под ним.

В PowerShell из корня проекта:

    cargo test --all-targets
    cargo build --release

Затем проверьте по очереди PPTX, PDF, видео и картинку: каждый показ должен быть виден поверх окон управления; при переключении фокуса строка должна стать красной, кнопка «Фокус» — вернуть показ. При закрытии каждого типа должен появиться фон.

ZIP проверен на целостность. Сборка и Windows/PowerPoint проверка здесь недоступны.
