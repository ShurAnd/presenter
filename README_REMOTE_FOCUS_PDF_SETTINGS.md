# Presentator 2.5.1 — фокус удалённого показа и выбор PDF-движка

## Установка

Архив рассчитан на текущую 2.5.1 с работающим исправлением видео video_order_fix2.
Сделайте резервную копию src, затем скопируйте все файлы из src этого архива
в src проекта с заменой. Соберите программу и обновите EXE НА ОБОИХ компьютерах.
Версия Cargo остаётся 2.5.1, поэтому одно совпадение номера версии не означает,
что оба компьютера уже получили этот патч.

Из корня проекта в Windows PowerShell:

```powershell
cargo test --all-targets stage19_
cargo test --all-targets
cargo build --release
```

Если команда завершилась ошибкой, сохраните полный вывод. После успешной сборки
закройте старые копии приложения и используйте новый target\release\presentator.exe
на презентационном компьютере и компьютере оператора.

## Изменения

- Один источник состояния фокуса для PPTX, PDF, видео и изображений — активное HWND Windows на компьютере показа.
- Опрос каждые 500 мс, потеря подтверждается двумя наблюдениями одного чужого окна.
- Фокус видео проверяется по окну сцены, которое принимает клавиатурные команды. Окно проигрывателя имеет NOACTIVATE.
- Панель фокуса видна только при подключении оператором и наличии активной презентации на сервере.
- «С фокусом всё в порядке» появляется только после подтверждения. Неизвестное состояние серое.
- Кнопка «Фокус» отправляет команду серверу. Сервер выбирает нужное окно и проверяет результат в течение двух секунд.
- Строка имеет постоянную высоту при активном показе. Название чужого окна доступно в подсказке при наведении.
- PDFium/Hayro выбирается в настройках оператора, применяется и сохраняется на сервере. Оператор видит фактический движок и ошибки сервера.
- При подключении к старому серверу, не передающему настройки PDF, вместо переключателя выводится просьба обновить сервер.
- Монитор показа, оконный режим и автозапуск пока остаются локальными настройками, как указано в интерфейсе.

## Проверка на двух компьютерах

1. Запустить сервер на презентационном компьютере, оператор подключается с другого ПК.
2. Открыть PPTX. На сервере переключиться в другое окно и подождать около секунды.
   У оператора должна появиться красная строка. На сервере этой панели быть не должно.
3. Нажать «Фокус» у оператора. Проверить восстановление управления с пульта на сервере
   и зелёное подтверждение у оператора.
4. Повторить для PDF, изображения и видео. Для видео проверить также паузу и продолжение.
5. Нажатия в окне оператора на отдельном компьютере не должны менять фокус сервера.
6. В настройках оператора переключить PDFium/Hayro. Проверить выбранный движок
   в настройках сервера и отображение PDF. При недоступном PDFium должен остаться
   прежний движок и появиться сообщение об ошибке.
7. Переподключиться оператором и проверить, что выбранный движок приходит с сервера.

## Проверки в архиве

Добавлены восемь stage19-тестов: переходы состояния фокуса для PDF/видео/изображений,
таймаут восстановления, независимость локального фокуса оператора, проверка команд PDF,
результат переключения движка, совместимость отсутствующих полей и реальный WebSocket
roundtrip статусов и команд. Обновлён старый тест, который ошибочно запрещал возврат фокуса для видео.

В среде подготовки нет Rust и Windows. Rust-тесты, сборка и сценарий на двух ПК
здесь не запускались. Проверены изменения исходников и целостность ZIP.
