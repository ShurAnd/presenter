# Presentator 2.5.1

- Исправлено определение оконного слайд-шоу PowerPoint и получение его HWND.
- Исправлена активация первого показа PPTX; добавлена повторная попытка восстановления фокуса по команде оператора.
- Исправлен переход PPTX → PDF и порядок окон сцены, слайд-шоу, видео и изображений.
- После закрытия показа сцена возвращает фон на передний план.
- Добавлены контроль фокуса и команда его восстановления для PPTX, PDF, видео и изображений.
- Добавлена компактная цветная строка статуса фокуса, скрытая при закрытом показе.
- Расширены тесты отказов, восстановления и получения HWND, подготовлены скрипты проверки покрытия.

Ручные проверки текущего состояния пользователем пройдены в проверенных сценариях. Проверка на нескольких мониторах ещё предстоит.

Установка версии: распаковать архив поверх текущего проекта с заменой Cargo.toml и Cargo.lock. Он меняет версию уже установленного кода; исходники последних исправлений не заменяет.

Сборка в PowerShell из корня проекта:

    cargo build --release

Ожидаемая строка сборки: Compiling presentator v2.5.1. Заголовок главного окна читает версию из Cargo.toml автоматически. Перед запуском новой сборки закройте прежние экземпляры приложения.
