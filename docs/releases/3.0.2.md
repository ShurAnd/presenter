# Presentator 3.0.2

Версия 3.0.2 — исправления по находкам эксплуатации 3.0.1 и ноябрьской ревизии:
белый фон вкладки «Плеер» в тёмной теме, курсор, который оставался виден на
показе сервера, если окно до этого работало оператором, и тихо умиравшее
соединение, которое не начинало переподключение. Протокол сети не менялся.

## Что изменилось

- **Плеер в тёмной теме.** Карточка списка треков была залита жёстким белым
  (`Color32::WHITE`) и оставалась белой в тёмной теме. Теперь она использует
  цвет поверхности темы — как карточка списка презентаций.
- **«Показать курсор» сбрасывается при смене роли.** Видимый над показом курсор
  делает ровно один флаг — «Показать курсор» на машине показа. Он не сохранялся
  только до перезапуска программы, но переживал смену роли: окно, работавшее
  оператором (или остававшееся автономным после разрыва связи), могло нести
  включённый флаг в сеанс сервера — и презентация, запущенная удалённым
  оператором, шла с видимым курсором. Теперь флаг сбрасывается в двух местах:
  при конце сеанса оператора («Отключиться», переключение на резерв, запуск
  сервера) и при запуске сервера. Включённая во время показа галочка работает
  как раньше — до конца текущего сеанса роли.
- **Мост PowerPoint ведёт журнал «мягких» сбоев.** Неудачи настроек, которые не
  должны ломать показ, раньше глотались молча: `ShowPresenterView` (режим
  докладчика), `Saved` (запрос о сохранении при закрытии), `PointerType`
  (видимость курсора в слайд-шоу), `Activate` (вывод слайд-шоу на передний
  план), `View.Exit` (завершение показа). Теперь каждая пишется в
  `presentator.log` с объяснением, что оператор увидит на экране, — поведение
  не менялось, показ по-прежнему не падает. Беззвучными остались только
  `Saved`/`Close` при закрытии: после `Exit` файл обычно уже закрыт, и их
  «ошибки» — норма.
- **Квадратики вместо символов убраны.** Из строк интерфейса убраны символы,
  которых нет во встроенном шрифте egui: «⏸ Пауза» → «Пауза» (кнопки видео,
  таймера, плеера и видео на слайде), «⚠» — из красной полосы проблемы и жёлтой
  полосы версий, «−» → «-» в справке и подсказке увеличения, размеры мониторов
  «1920×1080» → «1920x1080» («Настройки» и показатели сервера). Сканер
  `python scripts/scan_ui_symbols.py` теперь чист — прогонять перед релизом.
- **Тихая смерть соединения больше не висит.** Если канал умирал без
  TCP-ошибки (пропал Wi-Fi, закрылся NAT), клиент продолжал слать понги «в
  пустоту»: красная полоса «нет ответа» появлялась, но автопереподключение не
  начиналось, пока TCP не сдастся сам — минутами. Теперь молчание ответов
  дольше 10 с (проверяется после первого полученного `Pong` — старые серверы
  на пинги не отвечают, для них ничего не меняется) и зависшая отправка
  (дольше 5 с) разрывают соединение самому: «Сервер не отвечает N с —
  соединение разорвано», дальше — штатное автопереподключение. Загрузка файлов
  идёт по своему соединению и переподключения не боится.
- **Настройки пишутся атомарно.** `save_cfg` писал файл настроек напрямую:
  сбой посреди записи (нехватка места, выключение компьютера) оставлял битый
  `presentator_settings.json` — и программа теряла пароль, серверы, монитор и
  тему. Теперь запись идёт через временный файл и переименование
  (`config::write_atomic`), как у списка презентаций (`save_list`): прежний
  файл остаётся целым до успешной записи нового. Формат файла не менялся.

## Как воспроизводилась ошибка с курсором

В операторе галочка «Показать курсор» управляет флагом **сервера**; локальный
флаг окна при этом не меняется. Но если галку щёлкали, пока окно не было
подключено (автономный режим, пауза между разрывом связи и переподключением)
или раньше в этом же сеансе сервера, флаг оставался включённым до перезапуска
программы — «чтобы курсор не остался на показе» работало только при перезапуске.
Подтвердить можно по журналу: в `presentator.log` машины показа есть строка
`Команда: Cursor { on: true }`, а галочка в нижней панели сервера была включена.

## Совместимость

- Протокол WebSocket не менялся: 3.0.2 работает с 3.0.x и 2.5.4.
- Настройки и списки читаются без миграции.

## Проверки

- `cargo test` — 402 теста, 0 падений, 29 нативных/e2e пропущены; добавлены
  тесты `stage8_role_change_resets_show_cursor` (сброс флага при
  «Отключиться» и при запуске сервера),
  `client_task_breaks_silent_connection_after_pongs_stop` (фейковый сервер
  замолкает без закрытия TCP — клиент сам рвёт соединение) и
  `config_write_atomic_replaces_file_and_keeps_old_one_on_failure` (сбой
  записи не портит прежний файл настроек).
- `python scripts/scan_ui_symbols.py` — подозрительных символов нет.
- `cargo build --release` — `target/release/presentator.exe`.
- Вживую не проверено: тёмная тема плеера глазами, сценарий
  «оператор → сервер → запуск презентации с удалённого оператора», строки
  журнала моста (появляются, только когда PowerPoint реально отклоняет
  настройку — в нормальном прогоне их нет), кнопки «Пауза» и подписи
  мониторов «1920x1080» на экране.
