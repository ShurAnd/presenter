# Presentator 2.4.1 — фокус PPTX и предупреждение

Пакет рассчитан поверх применённого Stage 17 fix3 (обнаружение PPTFrameClass по имени PPTX). Распакуйте ZIP поверх проекта с заменой src/ppt.rs и src/ui.rs.

Изменения:
- После изменения порядка окон приложение явно активирует HWND слайд-шоу PowerPoint. Это выводит запущенную презентацию поверх обычных окон и даёт монитору фокуса корректную исходную точку.
- Предупреждение о потере фокуса стало плавающей панелью поверх интерфейса. Оно больше не занимает строку разметки и не сдвигает список презентаций.

Проверка в PowerShell из папки проекта:

    cargo test --all-targets
    $env:PRESENTATOR_STAGE12_NATIVE = 'I_UNDERSTAND'
    try {
        cargo test --all-targets stage12_native_ppt_three_slides_navigation_and_close -- --ignored --nocapture
    }
    finally {
        Remove-Item Env:\PRESENTATOR_STAGE12_NATIVE -ErrorAction SilentlyContinue
    }

Если тесты прошли, пересоберите приложение и закройте старые копии:

    cargo build --release

Проверьте запуск PPTX: слайд-шоу должно оказаться поверх окон Presentator. Затем переключитесь на другое окно: предупреждение на операторе появляется как плавающая панель, а список остаётся на прежнем месте. Нажмите кнопку восстановления фокуса.

Пакет проверен на целостность ZIP. Сборку и Windows/PowerPoint тесты в среде подготовки выполнить нельзя, так как здесь нет Cargo и Office.
