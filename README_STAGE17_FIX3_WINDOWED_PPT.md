# Presentator 2.4.1 — Stage 17 fix 3: оконный PowerPoint

Патч применяется поверх предыдущих исправлений Stage 17. Заменяет только src/ppt.rs.

По диагностике пользователя: COM возвращает «Член группы не найден» для HWND; записанный PID верный; окно демонстрации имеет класс PPTFrameClass и заголовок «Демонстрация PowerPoint - [stage12_three_slides.pptx [Нередактируемый]] - PowerPoint». Ранее запасной поиск принимал только screenClass.

Исправление: для оконного показа допускается PPTFrameClass, только если заголовок обозначает демонстрацию и содержит точное имя открываемого файла. Проверка PID и единственности подходящего окна сохранена. Обычное окно редактора PPTFrameClass не подходит. Для полноэкранного screenClass сохранён прежний поиск. Заголовки оконного показа поддерживаются для русского и английского Office; другие локализации этим правилом не определяются.

Тесты stage17_hwnd_fallback теперь содержат 4 проверки: полноэкранный показ и другой PID; неоднозначные/нулевые дескрипторы; реальный русский оконный заголовок из диагностики; английский заголовок, другое имя файла, пустое имя и два подходящих показа.

Распакуйте архив поверх D:\rust_projects\presenter с заменой файлов. В PowerShell из папки проекта выполните:

```powershell
cargo test --all-targets stage17_hwnd_fallback
$env:PRESENTATOR_STAGE12_NATIVE = 'I_UNDERSTAND'
cargo test --all-targets stage12_native_ppt_three_slides_navigation_and_close -- --ignored --nocapture
Remove-Item Env:\PRESENTATOR_STAGE12_NATIVE
```

Первый запуск должен найти 4 теста. Второй тест открывает настоящую презентацию и проверяет ненулевой HWND, навигацию и закрытие. После успеха:

```powershell
cargo test --all-targets
cargo build --release
```

Закройте старые копии программы и запустите обе копии обновлённого target\release\presentator.exe. Откройте PPTX в оконном режиме, переключитесь на другое окно, подождите 1–2 секунды, проверьте предупреждение у оператора, нажмите «Вернуть фокус PowerPoint» и проверьте стрелки пульта. Затем проверьте PPTX → PDF.

Диагностический вывод при ошибке сохранён. Если HWND опять останется 0, пришлите полный вывод нативного теста.

Проверка подготовки: состав и целостность ZIP проверены. Сборка и нативные тесты в среде подготовки не выполнялись: здесь нет Cargo/Rust и Windows/Office.
