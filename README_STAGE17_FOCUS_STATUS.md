# Presentator Stage 17 — статус фокуса и возврат фона

Распакуйте архив поверх папки проекта Presentator с заменой файлов. Он рассчитан поверх Stage 17 fix3 и последующего исправления отображения PowerPoint поверх окон.

После закрытия PPTX приложение сбрасывает состояние viewport сцены и запрашивает фокус повторно, чтобы фон вернулся на передний план. Статус фокуса отображается в компактной строке: зелёная «С фокусом всё в порядке», красная «Фокус сменился» и кнопка «Фокус». При восстановлении показывается короткий статус попытки.

В PowerShell из папки проекта:

    cargo test --all-targets
    cargo build --release

Закройте старые копии и запустите новый target\release\presentator.exe. Проверьте PDF и PPTX, затем закройте показ PPTX кнопкой приложения: фон должен снова выйти на передний план. Проверьте, что строка фокуса меняет цвет и список презентаций остаётся на месте ниже неё.

Изменения ZIP проверены на целостность. Сборка и ручная проверка требуют Windows/Rust/PowerPoint и здесь не выполнялись.
