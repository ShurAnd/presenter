# Presentator Stage 17 — сцена и показ всегда поверх обычных окон

Распакуйте поверх папки проекта с заменой src/stage.rs, src/ppt.rs и src/video.rs.

Сцена с PDF, картинками или фоном теперь остаётся в верхнем слое и в оконном режиме. Во время PPTX слайд-шоу помещается выше сцены. Во время видео окно проигрывателя помещается выше сцены, сама сцена остаётся непосредственно под ним. После закрытия внешнее окно убирается и зрителю снова виден фон. Картинки отображаются внутри окна сцены.

Проверка PowerShell:

    cargo test --all-targets
    cargo build --release

Закройте прежние копии, запустите новую сборку. Проверьте запуск/закрытие PPTX, PDF, видео и изображения, затем нажмите Win+D («Свернуть все») и убедитесь, что окно показа и фон остаются видны.

Если окно управления перекрывается сценой в оконном режиме, уменьшите или переместите сцену в настройках показа; верхний приоритет сцены сделан для зрительского экрана по требованию.

ZIP проверен на целостность. Rust-сборка, PowerPoint и Windows UI здесь недоступны, поэтому проверьте команды на своём Windows компьютере.
